# Smart Session Bot (লন্ডন + নিউ ইয়র্ক সেশন)

XAUUSD ও BTCUSD এর জন্য। বট নিজে মার্কেট বিশ্লেষণ করে, ইতিহাস থেকে শেখে, আর **শুধু লন্ডন ও নিউ ইয়র্ক সেশনে** কাজ করে।

## বট কী করে
1. **সেশন শুরুর ৩০ মিনিট পর** প্রতিটি সিম্বলের বিশ্লেষণ পাঠায়: 1H ট্রেন্ড, 15M গতি, ভোলাটিলিটি, গত দিনের হাই/লো, ওপেনিং রেঞ্জ, বায়াস।
2. প্রতিটি বন্ধ হওয়া 15M ক্যান্ডেলে দুই ধরনের সেটআপ খোঁজে: **ট্রেন্ড-পুলব্যাক** আর **সেশন ব্রেকআউট**।
3. প্রতিটি সেটআপ (সিগন্যাল দিক বা না দিক) `journal.csv` এ লিখে রাখে এবং ফল মিলিয়ে দেখে।
4. **ট্রেড সিগন্যাল পাঠায় কেবল তখনই**, যখন `model.joblib` আছে এবং সেটা অদেখা ডেটায় যাচাই পাস করেছে। নইলে **পর্যবেক্ষণ মোড**: শুধু বিশ্লেষণ, ট্রেড কল নয়।

সেশন লোকাল সময়ে ধরা হয় (লন্ডন ০৮:০০–১৬:৩০, নিউ ইয়র্ক ০৯:৩০–১৬:০০), তাই ডেলাইট সেভিং নিজে থেকে ঠিক হয়।

## কীভাবে "শেখে"
`research.py` ২ বছরের ইতিহাসে সব সেটআপ সিমুলেট করে, তারপর:
- **র‍্যান্ডম-এন্ট্রি বেঞ্চমার্কের** সাথে তুলনা করে
- **ওয়াক-ফরোয়ার্ড লার্নিং** (শুধু অতীত দিয়ে শেখা) দিয়ে ফিল্টার ঠিক করে
- **শেষ ২৫% সময় কখনো ছোঁয় না**; সেখানে একবারই পরীক্ষা করে
- গেট: গড় ≥ +0.05R, t ≥ 1.64, কমপক্ষে ৩০ ট্রেড, র‍্যান্ডমের চেয়ে ভালো

পাস করলেই `model.joblib` সেভ হয়। প্রতি মাসের ১ তারিখে নতুন ডেটায় আবার শেখে; ফেল করলে পুরনো মডেল মুছে বট পর্যবেক্ষণ মোডে ফিরে যায়।

## সেটআপ
1. সব ফাইল নতুন GitHub repo তে আপলোড করুন (`.github/workflows` সহ)।
2. Settings → Secrets: `TWELVE_DATA_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
3. Settings → Variables: `XAU_SPREAD` (যেমন 0.30), `BTC_SPREAD` (যেমন 15) — ব্রোকারের আসল স্প্রেড দিন।
4. Actions → **Research and Learn** → Run workflow (প্রায় ১৫–৩০ মিনিট)। শেষে `report.txt` পড়ুন।
5. Actions → **Smart Session Bot** চালু রাখুন। মডেল পাস না করলেও বিশ্লেষণ আসবে।

## সৎ সীমাবদ্ধতা
- আসল বাজারে এজ আছে কি না আমি জানি না। রিসার্চ রিপোর্টই সেটা বলবে। নকল (র‍্যান্ডম) ডেটায় পাইপলাইন সঠিকভাবে FAIL করেছে, মানে ভুয়া এজ বানায় না।
- ব্যাকটেস্টে একই ক্যান্ডেলে SL ও TP ছুঁলে SL ধরা হয়; স্প্রেড স্থির ধরা হয়; নিউজ ফিল্টার নেই।
- PASS মানে প্রমাণিত নয়। ১-২ মাস সিগন্যাল দেখে (ডেমোতে) মিলিয়ে তবে আসল টাকা।
- ছোট রিস্ক রাখুন। এটা আর্থিক পরামর্শ নয়।
